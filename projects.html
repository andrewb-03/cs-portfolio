Sworn In USA — E-Commerce Web Application

Designed and engineered a full-stack e-commerce web application for Sworn In USA, an American lifestyle clothing brand. Built from the ground up with a custom dark premium aesthetic, full shopping cart functionality, SMS and email order notifications, and a complete checkout flow. Completed as a solo freelance engagement.

Key highlights

  • Custom homepage with cinematic lifestyle photography and animated marquee
  • Full product catalog with category filtering and size, color, and gender selectors
  • Slide-out cart drawer with quantity controls, promo code validation, and order summary
  • Multi-step checkout flow with form validation and order confirmation page
  • SMS notifications via Twilio for owner alerts and customer confirmations
  • Email notifications via EmailJS; SEO optimized with metadata, sitemap, and JSON-LD
  • Persistent cart via localStorage; fully responsive across all devices
